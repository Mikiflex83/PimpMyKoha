# Confidentialité

La cartographie des adhérents reste désactivée en fresh-install tant qu’une validation de confidentialité n’est pas explicitement fournie. Aucune adresse ne doit être journalisée. Privilégier l’import de coordonnées pré-géocodées si possible. Les modules Qualité n’envoient pas de données personnelles métier vers leur mémoire Firebase.
