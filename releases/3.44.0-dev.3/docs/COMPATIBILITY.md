# Compatibilité Koha

| Version | Statut V3.42 |
|---|---|
| 25.11.x | cible principale, recettes à exécuter sur l’installation |
| 25.05.x | compatible sous réserve du préflight API/DOM |
| 24.11.x | compatible sous réserve du préflight API/DOM |
| antérieure | non déclarée supportée |

Les modules doivent privilégier les identifiants techniques (`data-colname`, API, attributs stables) puis les alias d’en-têtes multilingues. Les index fixes ne sont qu’un dernier recours.
